Quick start
  1. Setup → Manual host: enter the IP and port of your pypilot_web (port 80 on TinyPilot by default). Apply & reconnect.
  2. Setup → Emergency: save the TinyPilot SSH user + password. The RESTART pypilot button then reboots the remote process without leaving the browser.
  3. Control: tap AP to engage the pilot on the current heading. ±1 / ±10 nudges the target. TACK ⟨ / ⟩ tacks to port or starboard. The centre dropdown switches the mode (compass / gps / wind / true wind / nav).
  4. Rose: N (orange) / E (green) / S (blue) / W (red) plus degree ticks every 30°. Green / red wedges are hull-fixed and mark the sailing zones.
  5. Gota Chain: three concentric arrow pieces on the rose — cyan diamond (AP target), amber (AWA, marked A), sea-green (TWA, marked T). When target ≡ AWA ≡ TWA they interlock into one clean "gota" (droplet); the moment any of the three drifts, its V-notch opens and its color ring-tick reveals the exact angle.
  6. Overlays: long-press any corner OR the boat sprite to open the 4-card selector for AWA / TWA / COG line / current vector (SOG−SOW). Each card lists what data it needs.
  7. Corners: same long-press menu picks which datum shows in each corner (HDG, wind, SOG, COG, target, depth, mode, polars…).
  8. Tune: tick Unlock settings before touching. Each slider has −10 / −1 / slider / +1 / +10. When unlocked, the previous value is shown in orange as a reference.
  9. Race: T1/T2 countdown timer with audible beeps + screen flash + spoken seconds. Runs in the background across tabs.
  10. Paths & API: Signal K paths this plugin publishes. Wire the Simple Switch rows (blue) to KIP.
  11. Swipe: drag horizontally across any tab to go to the next / previous. Blocked over unlocked sliders and horizontally-scrollable tables.
  12. Tab bar: tap the yellow triangle at the bottom-centre to hide it and give the rose more room.
Instrucciones rápidas
  1. Setup → Manual host: escribe la IP y puerto de tu pypilot_web (por defecto 80 de la TinyPilot). Apply & reconnect.
  2. Setup → Emergency: guarda el usuario+password SSH de la TinyPilot. Con eso el botón REINICIAR pypilot reinicia el proceso remoto sin salir del navegador.
  3. Control: pulsa AP para enganchar el piloto en el rumbo actual. ±1 / ±10 mueve el rumbo objetivo. VIRAR ⟨ / ⟩ vira por babor o estribor. El desplegable central cambia el modo (compass / gps / wind / true wind / nav).
  4. Rosa: N (naranja) / E (verde) / S (azul) / W (rojo) y grados cada 30°. Sectores verde/rojo fijos a la crujía marcan las zonas de amura.
  5. Gota Chain: tres piezas concéntricas en la rosa — diamante cyan (target del AP), amber (AWA, letra A), verde-mar (TWA, letra T). Cuando target ≡ AWA ≡ TWA se ensamblan en una "gota" limpia; en cuanto una se desalinea, su V-hembra queda hueca y su rayita de color en el aro marca el ángulo exacto.
  6. Capas: long-press en cualquier esquina O sobre el barco abre el selector de 4 tarjetas: AWA / TWA / línea COG / vector corriente (SOG−SOW). Cada tarjeta indica qué datos necesita.
  7. Esquinas: el mismo menú long-press elige qué dato ver en cada esquina (HDG, viento, SOG, COG, target, sonda, modo, polares…).
  8. Ajustes: marca Desbloquear ajustes antes de tocar. Cada slider tiene −10 / −1 / slider / +1 / +10. Al desbloquear ves el valor original en naranja para saber contra qué comparas.
  9. Regata: timer T1/T2 con beeps + flash de pantalla + voz. Corre de fondo en cualquier pestaña.
  10. Paths & API: paths SK que este plugin publica. Usa los Simple Switch (fila azul) para conectar con KIP.
  11. Swipe: desliza el dedo horizontalmente en cualquier pestaña para cambiar a la siguiente / anterior. Bloqueado sobre sliders desbloqueados o tablas con scroll horizontal.
  12. Barra de pestañas: pulsa el triángulo amarillo (abajo del centro) para ocultarla y ganar espacio para la rosa.

Working alongside pypilot-autopilot-provider

This plugin builds on top of the excellent work by Panaaj with pypilot-autopilot-provider. That plugin gives Signal K the standard Autopilot API v2 (/signalk/v2/api/vessels/self/autopilots/*) — the canonical interface used by WilhelmSK, freeboard and other clients to drive the pilot. It focuses tightly on that API and opens its own socket.io connection to pypilot_web.

We add on top ~50 paths Panaaj does not cover (gains, servo, calibration, warnings, profiles, tack detail…), the touch UI, and — optionally — an Absorb Provider mode (Setup) that registers the Autopilot API v2 from this plugin itself, leaving a single connection to pypilot_web (handy on Pi Zero W).

Signal K only allows one provider per pilot ID, so if you enable Absorb here you should disable Panaaj's plugin (otherwise both try to register the same AP). Sensible setups:

  • Panaaj ON + Absorb OFF (default): both work happily together. Panaaj owns the AP v2 API, we add the extra paths and the UI. 2 sockets to pypilot_web.
  • Panaaj OFF + Absorb ON: only this plugin. Same AP v2 API + all the extras. 1 socket. Handy on Pi Zero W.
  • Panaaj ON + Absorb ON: both try to register the same AP — leave one off.
  • Panaaj OFF + Absorb OFF: WilhelmSK / KIP won't see the AP. Only if you use this webapp exclusively.
